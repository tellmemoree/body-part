# Spare Parts

A roguelite where you lose, find and swap body parts. Godot 4.7, tilted top-down 3D.

- [PLAN.md](PLAN.md): the design, what is done, what is next, how to run and test
- [ARCHITECTURE.md](ARCHITECTURE.md): how the code is organised, for anyone changing it

Play: open the folder in Godot 4.7 and press F5.
